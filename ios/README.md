# iOS-версия

Игра собирается для iPhone/iPad (arm64, iOS 15+) через Xcode SDK на macOS. Игровые ресурсы общие с Android: `game/assets`.

```sh
bash ios/build.sh
```

Результат: `downloads/FunnyWorld-0.1-unsigned.ipa`.

GitHub Actions автоматически собирает IPA при изменении iOS-кода и публикует его в [Releases](https://github.com/sohalegenda-wq/fuzzy-spoon/releases). Можно также запустить workflow вручную из вкладки Actions.

**IPA не подписан Apple. Простое открытие файла на iPhone не установит игру.** Нужны подпись и профиль вашего Apple ID/команды разработчика, например через подходящий инструмент установки приложений с собственной подписью. Пароли Apple ID, сертификаты и закрытые ключи в репозиторий добавлять не нужно.

Это не сборка для App Store или TestFlight. Установка и работа на физическом iPhone пока не проверены. Автоматическая проверка подтверждает компиляцию ARM64, структуру пакета и контрольную сумму.
