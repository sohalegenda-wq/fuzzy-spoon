# Весёлый мир: Симфония страха

Игровой прототип для Android и iOS, версия 0.1.0.

## Скачать игру

**[Скачать готовый APK](https://github.com/sohalegenda-wq/fuzzy-spoon/raw/refs/heads/main/downloads/FunnyWorld-0.1.apk)**

Android 6.0+ с актуальным Android System WebView. Откройте APK на телефоне и разрешите установку из выбранного файлового менеджера, если Android запросит это. Игра работает без интернета. Ориентация экрана — горизонтальная.

## Содержимое

- 35 помещений, исследование от первого лица и сенсорное управление.
- Спасение команды, пять ключей, архив, дневник и финальный выбор.
- Аниматроники, укрытие, фонарь и автосохранение.
- Исходный код в `game/`, инструкция в `docs/README-ru.txt`.

Это небольшая версия с упрощённой псевдо-3D графикой, а не полная реализация масштабного хоррора. Игровая логика проверена в Chromium; подпись APK проверена. На реальном Android-устройстве сборка пока не тестировалась.

## Сборка

Нужны Java, Android SDK Platform 35, Build Tools 35.0.0, Eclipse Java Compiler (ECJ), `zip` и `keytool`.

```sh
cd game
SDK=/path/to/android-sdk ECJ=/path/to/ecj.jar bash build.sh
```

Скрипт создаёт локальный тестовый ключ, если его нет. Исходный закрытый ключ подписи опубликованного APK не включён. Сборка с новым ключом не сможет обновить установленный APK без удаления предыдущей установки (сохранение будет потеряно).
